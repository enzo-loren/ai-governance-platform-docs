Qué controla esta configuración

La puerta observa solicitudes y respuestas del modelo, además de las intenciones de usar herramientas.

Límite principal

La ejecución de herramientas externas no se controla; el principal de las políticas es el agente.

* Los porcentajes son referencias del índice de cobertura del catálogo de insumo/, no porcentajes de seguridad: modo activo, agente con tools y usuarios, conexiones completas y evaluaciones con evidencia. En la práctica, B se mide por tools integradas y C por solicitudes con JWT válido; ambas pueden ser parciales. La página representa el diseño conceptual objetivo, no el despliegue AWS ni la conexión efectiva de un agente.

Fuentes, explicaciones y diagramas anteriores

El salto usuario → agente es responsabilidad del cliente. C requiere que el agente reenvíe un JWT válido (en inferencia y, cuando corresponda, en MCP). B controla la ejecución de herramientas solo cuando pasan por la puerta. Un agente aún puede utilizar otros caminos de red o credenciales. Las aprobaciones humanas y la separación de funciones dependen de las reglas aplicables, no solo de activar las conexiones.
